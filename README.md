# 🏥 Smart Healthcare Appointment System

A Django-based web application designed to simplify doctor-patient appointment booking and improve communication through automated Telegram notifications.

## 📌 About the Project

The **Smart Healthcare Appointment System** is a web-based application that makes doctor-patient appointment scheduling easier and more convenient. It allows users to manage appointment bookings while providing real-time Telegram notifications for bookings, updates, and reminders.

The project aims to improve communication and provide a smoother healthcare appointment experience.

## ✨ Features

- **Appointment Booking:** Simplifies doctor-patient appointment scheduling.
- **Telegram Notifications:** Sends notifications for appointment bookings and updates.
- **Appointment Reminders:** Helps users stay informed about scheduled appointments.
- **User-Friendly Interface:** Provides a simple interface for appointment-related activities.

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the Project Directory

```bash
cd Smart-Healthcare-Appointment
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Apply Migrations

```bash
python manage.py migrate
```

### 5. Run the Development Server

```bash
python manage.py runserver
```

### 6. Open in Browser

Visit:

```text
http://127.0.0.1:8000/
```
